# Security policy

Security fixes target the latest version on `main`; older versions do not have
a separate support commitment.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials or private data in public issues
or pull requests. Use GitHub's private vulnerability reporting:

https://github.com/Yadavbalbir/motion-studio/security/advisories/new

Include affected versions, reproduction steps, the impact and a minimal proof
of concept without real credentials or personal data. Please allow maintainers
time to investigate and coordinate a fix before public disclosure.

If you accidentally exposed an API key, revoke or rotate it immediately.
Deleting a file or comment alone does not invalidate a credential.
